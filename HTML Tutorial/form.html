FAQs
1. Which fields are required?

Currently, only the Date of Admission field is required.

2. Can I reset the form?

Yes, click the Reset button to clear the form and restore its default values.

3. Can I upload a file?

Yes, use the Upload Evidence option to select a file from your device.

4. Is my password visible while typing?

No, the password field hides the characters by default.

5. Can I select multiple languages?

Yes, you can select multiple programming languages using the checkboxes.

6. What happens when I click Submit?

The browser attempts to submit the form, but a server is needed to process and store the information.
